# ClutterSloth 🦥

**Automated File Sorting via a Local Browser Loop**

## 📌 Overview
ClutterSloth is a lightweight productivity tool built to eliminate the procrastination of organizing messy folders. Using a local browser loop, it automatically sorts and categorizes cluttered files in seconds without manual effort.

## 🔗 Live Demo & Write-Up
* **Live Deployed App:** [Launch ClutterSloth](https://pug-tape-64702791.figma.site)
* **DEV.to Project Article:** [Read on DEV.to](https://dev.to/sumedha_ghosh_302008/cluttersloth-sorting-5-messy-files-took-me-12-minutes-of-procrastination-so-now-a-local-browser-9f9)

## ✨ Key Features
* **Automated File Sorting:** Organizes messy files into clean categories automatically.
* **Local Browser Loop:** Runs smoothly right inside the browser with zero heavy setup.
* **Time-Saving Workflow:** Turns a 12-minute manual task into an instant background process.
